# Events7

Events7 is a web application created for the "Software Engineer Expertise Test" by Matej Žan to participate in the selection process for a Frontend Developer position at Outfit7. The app itself is a tool to define the events the Analytics team would like to track.

## Local development/testing

Run `git clone https://github.com/matejzan/Events7.git` to clone the source code to your local repository and `cd Events7` to move to your cloned repository.

Run `npm install -g @angular/cli` to install command line interface.

Run ` npm install` to install dependencies. It might take a minute or two.

Run `ng serve` for a dev server. Navigate to `http://localhost:4200/`. The app will automatically reload if you change any of the source files.

## Deployed version

Visit https://events7-9c487.web.app/ to test the deployed version.

## Build

Run `ng build` to build the project. The build artifacts will be stored in the `dist/` directory.
